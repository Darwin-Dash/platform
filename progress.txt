## Key Learnings

### Build Configuration
- Webpack config needs Node.js polyfill fallbacks for browser builds
- dist/evo-sdk.module.js stub required for test execution
- TypeScript compiles cleanly with current tsconfig.json

### Architecture Patterns
- Documents facade uses modern typed options API matching wasm-sdk
- DocumentsQuery for queries
- DocumentCreateOptions, DocumentReplaceOptions, etc. for mutations
- All methods wrapped with withErrorHandling for better debugging

### DashPay Patterns
- DashPay uses DocumentsQuery for profile/contact lookups
- Three document types: profile, contactRequest, contactInfo
- Profile queries use $ownerId filter for identity lookup
- Contact request queries support pagination via timestamp (startAfter)
- Mutation methods delegate to documentCreate/documentReplace
- deriveContactKey uses static WasmSdk.deriveDashpayContactKey

### Known Issues
- Webpack build has issues due to Node.js dependencies in Identity facade
  (winston, wasm-x11-hash, etc.) - this is a Phase 1 issue
- 9 deprecated method tests failing - not blocking development
